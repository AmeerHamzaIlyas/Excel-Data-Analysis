# Excel Data Analysis Project

## Project Overview

This project demonstrates data analysis and data manipulation using Microsoft Excel. 
The dataset was analyzed using different Excel functions and formulas to  
transform, organize, and extract meaningful information from the data.

## Objectives

- Analyze and organize the given dataset
- Apply different Excel functions for data manipulation
- Clean and transform the data
- Combine and extract information from multiple columns
- Translate text into different languages where required
- Generate meaningful results from the dataset

## Excel Functions Used

The project includes the use of various Excel functions, such as:

- TEXTJOIN – Used to combine text from multiple cells with a specified delimiter.
- IF – Used to apply logical conditions.
- COUNT / COUNTA – Used to count values and non-empty cells.
- SUM – Used to calculate totals.
- AVERAGE – Used to calculate average values.
- LEFT / RIGHT / MID – Used to extract specific parts of text.
- LEN – Used to determine the length of text.
- TRIM – Used to remove unnecessary spaces.
- CONCAT – Used to combine text values.
- SUMIF - used for muliple conditions
- GOOGLETRANSLATE – Used for translating text between different languages.
- PIVAT TABLE
- CHART
- DROP DOWN etc

## Tools Used

- Microsoft Excel
- Excel Functions & Formulas
- Google Sheets / Google Translate functions (where applicable)

## Key Learning

Through this project, I practiced using Excel functions for real-world data 
manipulation and analysis. The project helped strengthen my understanding of 
text functions, logical functions, data cleaning, and formula-based analysis.
